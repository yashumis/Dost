# Dost – floating cartoon friend (Android)

GitHub builds the app automatically every time files are uploaded.
Download it from the **Releases** section (right side of the repository page) → **Dost.apk**.

What it does: floating face over every app, hands-free Hindi/other-language conversation,
emotions, blinking, lip movement in time with the voice, jokes, tasks, reminders (ring even when
the phone is locked), calls from your phone contacts, internet answers (Gemini + Google Search),
optional ElevenLabs premium voice.
